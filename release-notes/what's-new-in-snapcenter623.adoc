= SnapCenter 软件 6.2.3 中的新增功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
6.2.3 版本的 SnapCenter software 没有新增功能或增强项。

该版本仅包含已知错误修复以及 SnapCenter Server 和插件的合格版本更新。有关更多详细信息，请参阅 link:https://library.netapp.com/ecm/ecm_download_file/ECMLP3359467["SnapCenter 发行说明"^]。

要将主机升级到 SnapCenter 6.2.3，请参见 link:https://library.netapp.com/ecm/ecm_download_file/ECMLP3359467["SnapCenter 发行说明"^] 中的 *将主机升级到 SnapCenter 6.2.3*，了解有关升级主机的更多详细信息。
